ARIZE

Study · Focus · Grow — a personal macOS study planner for AFK / NDEB exam preparation.

What ARIZE does

ARIZE is a private desktop app used by one dental student to plan reviews, practise exam questions and track mistakes. All study data is stored locally on the user's Mac.

Optional Google Drive sync

If the user chooses to connect Google Drive, ARIZE creates one folder named ARIZE — AFK Mistake Recovery containing four documents (Knowledge Gap, Forgot, Confusion, Misreading) and keeps them up to date. It uses the limited drive.file permission, so it can only access files it created itself.
